# Roadmap

- **HTML:** incremental refinement only.
- **CSS:** expand to modern layout topics such as Grid only when actually studied or approved.
- **JavaScript:** grow according to real learning progress.
- **React:** become a separate knowledge area when sufficient learning material exists.
- **Web fundamentals:** HTTP, request/response, headers, JSON, and REST may eventually form a cross-cutting area.

This is a direction record, not tutorial content or proof that these topics are already learned.
