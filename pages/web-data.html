02 JSON

JSON 与 JavaScript object

JSON（JavaScript Object Notation）与 JavaScript object 都可写成 key: value 字段集合，但用途不同：object 是程序运行中的值；JSON 是保存或交换数据的文本。JSON 的 key 必须用双引号；不能含 function、undefined 或 class instance，而 object 可以。

比较点JSONJavaScript object
主要用途保存或交换数据的文本程序运行中的值
key 写法必须使用双引号可按 JavaScript object 语法书写
可含内容不含 function、undefined 或 class instance可含这些程序运行时的值

课程列出的价值与用途

  • 轻量、人易读改、机器易解析/生成、跨语言/平台、传输安全。
  • 可嵌套对象和数组、流式分段处理大数据、无需预先固定 schema 而新增字段。
  • 常见于配置、小项目的轻量数据存储和 API 服务器数据。

JSON 与 object 之间的转换

const object = JSON.parse('{"name":"Siyu"}'); // JSON → object
const text = JSON.stringify(object);            // object → JSON

04 fetch()、Promise 与异步

fetch() 立刻给什么

网络需要时间，JS 不应傻等。调用 fetch() 时，它同步地、立刻返回一个 pending Promise；真正的网络请求交给浏览器 Web API 在后台处理。

Promise 的状态Promise 不是 API 完成后才创建：它先作为“空壳”存在，结果回来后才变为 fulfilled，失败则变 rejected。
1. fetch()
 ↓
2. 立刻返回 pending Promise；当前 JS 继续
 ↓
3. 浏览器 Web API 请求服务器
 ↓
4. 结果回来 → Promise fulfilled / rejected
 ↓
5. .then()/.catch() 或 await 后的处理运行

结果回来后如何继续

  • 结果就绪后，浏览器把后续工作放入 microtask queue；Event Loop 在 Call Stack 空闲时让它执行。
  • JS 并非同时做两件事，而是把耗时工作交给浏览器，之后再继续结果处理。
  • .then()/.catch() 把成功/失败回调挂在 Promise 上；async 允许函数内使用 await，await 让该 async 函数的后续代码等结果后再继续。两种写法底层都是 Promise。

await 读取结果

async function getData() {
  const res = await fetch(BIN_URL);
  console.log("这行代码不会提前跑");
  const data = await res.json(); // .json() 也是异步的
}

05 Response、Headers 与 Status

读取 response body

fetch() 返回 response 后，res.json() 才读取并解析 JSON；它也是异步的，所以同样 await。

Headers

headers 是 request/response 的元数据：request headers 给服务器上下文，如 API key；response headers 描述返回内容。

06 课程实操与安全

jsonbin.io 课堂实操

课程以 jsonbin.io 作临时 JSON API server：创建 Bin、保存 mock JSON、复制 URL 和 key。

  • GET 把 key 放在 headers 并读取 res.json()。
  • POST 增加 method、Content-Type 和 JSON.stringify(newRecord) body。
  • PUT 近似 POST；DELETE 没有 body。

React discussion 的真实 GET

真实 GET 把 numArtworks 放进 limit query parameter，解析后以 setArtworks(json.data) 保存，再由 map 显示。

CS303 / MP-2 安全红线 前端只用 GET；不要把 POST、PUT、DELETE 和 API_KEY 放在浏览器源码，因为用户可查看 key。服务端写入留待后续课程。
更准确的课程简写 “大于 299 没按预期走通”是课堂调试简写；200–299 都属成功范围（含 299），300–399 是重定向，不必然是错误。先看具体 status 和场景。
