CSS：布局与视觉呈现

CSS（Cascading Style Sheets）告诉浏览器 HTML 内容如何呈现。先理解规则如何作用于盒子，再记属性。

01 CSS 基础、语法与三种引入方式

定义与价值

CSS 是层叠样式表：用样式规则描述 HTML 的呈现。它把内容与设计分开；一个 .css 文件能控制多个 HTML 页，因此更容易统一更新、协作、适配设备并保持 DRY（不重复自己）。

selector {
  property: value;
}

<link rel="stylesheet" type="text/css" href="css/site.css">
<style>p { color: navy; }</style>
<p style="color: navy">...</p>
方式 何时与如何
外部 CSS 独立 .css 文件；用 link 放在 head，适合多页项目。rel、type、href 是课程笔记强调的 link 部分，href 随文件位置而变。
内部 CSS 写在当前 HTML 的 head > style，只影响该页，适合学习/小实验。
行内 CSS 写在单个元素的 style 属性，混合结构和外观，通常少用；课程笔记提到它常与 JavaScript 配合。
课程笔记 + 更准确的理解

课程把优先级概括为 external → internal → inline。这个顺序可帮助初学者记住行内规则常更强；但真正冲突还受 selector specificity、源码顺序和其他层叠规则影响，不能把它当成所有情况的唯一公式。文件寻址仍从当前 HTML 算：同目录可写 href="demo.css"，../ 回上级，../../styles/home/demo.css 跨多个目录。

02 选择器、继承、层叠与优先级

p {}             /* tag */
.card {}         /* class */
#hero {}          /* id */
* { margin: 0; box-sizing: border-box; }
nav a {}          /* descendant */
nav > a {}        /* direct child */
h1, h2 {}         /* group */
button.primary {} /* intersection */
a:link {} a:visited {} a:hover {} a:focus {} a:active {}

选择器寻找需要设样式的元素。标签选择器会选中所有同名标签；类选择器 .class 适合重复使用，一个元素可有多个用空格分开的 class，类名应见名知意、使用英文/连字符而不是纯数字或中文。#id 选唯一 id，课程笔记认为它更常与 JavaScript 配合。通配符 * 选全页元素，常用于清除浏览器默认间距。

后代选择器用空格，匹配任意深度的后代；子代选择器 > 只匹配直接孩子；并集用逗号给多组相同样式；交集连写，要求同一元素同时满足条件。伪类用冒号表示状态；链接状态按课程口诀 LVHFA（link、visited、hover、focus、active）书写以减少覆盖问题。

三个容易混淆的概念

继承（Inheritance）让部分属性（如 color）从父元素传给孩子；层叠（Cascade）在规则冲突时决定胜者；优先级（Specificity）比较选择器权重，权重相同再看源码后出现的规则。不要急着用 !important，先检查选择器、结构和规则顺序。

03 字体、文本、颜色与背景

body { font-family: Arial, sans-serif; font-size: 16px; line-height: 1.6; }
h1 { font: italic 700 30px/2 sans-serif; text-align: center; }
p { text-indent: 2em; text-decoration: underline; }
.note { color: #fc0; background-color: rgba(20, 40, 90, .2); }

文字常用 font-size（PC 常见 px）、font-weight（400/700 或 normal/bold）、font-style（normal/italic）、line-height、font-family。font-family 可从左到右写多个候选，最后给通用 sans-serif。font 简写顺序是 style、weight、size/line-height、family；字号和字体必须出现，否则简写不生效。单行文字要在固定高度盒子中垂直居中时，可令 line-height 等于盒子高度。

text-indent 可用 px 或 em（1em 是当前字号），text-align 控制水平 left/center/right，text-decoration 可为 none/underline/line-through/overline。颜色可用英文名称、#RRGGBB（可缩写 #RGB）、rgb()、rgba()，以及来源也覆盖的 HSL/HSLA；alpha 范围是 0（全透明）到 1（不透明）。背景常见 background-color、image、repeat、position、size；cover 可填满但可能裁剪，contain 保留完整图片但可能留空。

04CONTENT真实内容

元素真正承载内容的区域

* { margin: 0; box-sizing: border-box; }
.box { width: 200px; padding: 30px; border: 5px solid orange; }
/* without border-box: 200 + 30 + 30 + 5 + 5 = 270px */
margin: 50px;              /* all */
margin: 50px 70px;         /* top/bottom | left/right */
padding: 10px 70px 20px;   /* top | left/right | bottom */
padding: 20px 10px 50px 70px; /* top right bottom left */

content 是内容，padding 是内容到边框的内部空间，border 包住它们，margin 是盒子与其他盒子的外部距离。border 的三部分是 width、style、color；常用 style 有 solid、dashed、dotted，简写如 border: 5px solid red，也可写 border-top/right/bottom/left。

相邻普通 block 的垂直 margin 可能折叠：40px 的 margin-bottom 与 25px 的 margin-top 实际通常是 40px，不是 65px；水平方向不这样折叠。padding 不折叠，但默认会增加总尺寸。box-sizing: border-box 让声明的 width/height 包含 padding 和 border，避免计算把布局撑大。水平居中有两种来源方法：eligible block 写 margin: auto；inline 内容在父元素上写 text-align: center。

05 Display、Flexbox、定位与两栏布局

.row { display: flex; flex-direction: row; justify-content: space-between;
       align-items: center; flex-wrap: wrap; gap: 1rem; }
#container { display: flex; }
nav { width: 30%; } main { width: 70%; }
.parent { position: relative; }
.badge { position: absolute; top: 0; right: 0; z-index: 2; }

block 通常另起一行并可设尺寸；inline 在文字流中；inline-block 行内排列但可设尺寸；none 从布局移除。图片默认 inline，能用 display: block 改变。Flexbox 属性写在父元素：flex-direction 定义主轴，justify-content 沿主轴分配，align-items 沿交叉轴对齐，gap 是项目间距，flex-wrap 控制是否换行，不能把它当成方向。

定位：static 是默认正常流；relative 相对原位置偏移并保留原空间；absolute 脱离正常流、相对最近 relative 父元素；fixed 固定相对视口，常见于导航/返回顶部。z-index 管理有定位元素的层叠顺序，数值大通常在上，但先确认定位和 stacking context。两栏练习中 nav 30% + main 70% 是起点；若再加 gap/边距可能溢出，需检查总宽度。

06 响应式设计、单位与媒体查询

<meta name="viewport" content="width=device-width, initial-scale=1">
img { max-width: 100%; height: auto; }
h1 { font-size: calc(2px + 2vw); }
@media (max-width: 700px) { .row { flex-direction: column; } }

响应式设计让内容适应可用空间，而不只是在手机上缩小。课程来源使用 px、%、vh、vw 和 calc()：% 相对父容器，vh/vw 相对视口；calc() 组合数值，运算符前后要有空格。viewport、相对单位、弹性布局、max-width 图片与媒体查询一起使用。断点应在布局开始挤压时决定，而不是背一个神秘数字。

07 伪类、过渡、视觉层级与可访问性

a:hover { color: hotpink; }
button { transition: background-color 180ms ease, transform 180ms ease; }
/* shorthand: property duration timing-function delay */
div { transition: width 2s linear 1s; }

伪类通过 : 表示状态，例如 hover、focus、active；focus 不能只靠鼠标 hover，因为键盘用户需要可见焦点。transition 有 property、duration、timing-function、delay；简写中两个时间值的第一个是 duration、第二个是 delay。把 transition 写在初始规则，给用户可理解的状态变化使用。

用大小、颜色、留白和对齐建立视觉层级，但不只用颜色传达状态；保持足够对比度、清楚的表单 label、可见 focus 和足够点击面积。表格应有可读表头、padding 和合适边框处理。

08 DevTools、常见错误与项目踩坑

从真实匹配关系调试

右键检查或 F12 打开 DevTools：Elements 看真实 DOM，Styles 看哪些属性生效/被覆盖，Box Model 看尺寸；错误属性可能有黄色感叹号，属性前复选框能临时关闭规则。不要猜，先 Inspect 目标。若 #container { display:flex } 无效，确认 HTML 真的有该 id；class/id 的拼写和大小写必须一致。flex-wrap 不会改主轴；nav 30% + main 100%（或 70% 再加 gap）会溢出；padding 没有 border-box 会撑大宽度。
