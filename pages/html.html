HTML：网页的结构与语义

HTML 说明内容是什么；CSS 处理外观与布局，JavaScript 添加行为与交互。

01 HTML 与 HTML5 文档

定义

HTML 是 HyperText Markup Language（超文本标记语言）。超文本能连接到其他文字、图片、视频或媒体；标记语言通过预先定义的标签组织文档内容。HTML、CSS 和 JavaScript 是抽象层：开发者用结构和含义表达网页，而不是逐像素绘制。

<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Child | Parent</title>
  </head>
<body>Visible content</body>
</html>
  • <!doctype html> 声明 HTML5；在 VS Code 输入 ! 可由 Emmet 建立骨架。
  • lang 标识内容语言，charset="UTF-8" 解码中英文等字符与符号。
  • head 放给浏览器/搜索引擎的声明信息：meta、title、link、script；body 放用户看到的内容。课程笔记建议 title 使用“子页面 | 父站点”格式。

02 元素、文本、列表与嵌套

成对标签有开始与结束，例如 <h1></h1>、<p></p>、<a></a>、<li></li>；空元素如 hr、br、img、meta 没有结束标签。元素可以嵌套，例如 <ul><li>…</li></ul>，但要按相反顺序关闭。缩进不是强制语法，却是检查父子关系的惯例；注释写作 <!-- … -->。

<h1>One page title</h1>
<p>A paragraph with <strong>importance</strong> and <em>emphasis</em>.</p>
<ul><li>Unordered item</li></ul>
<ol><li>Ordered step</li></ol>
<dl><dt>Term</dt><dd>Description</dd></dl>

h1–h6 表示标题层级，p 是段落；strong/b、em/i、ins/u、del/s 分别呈现加粗、斜体、下划线与删除线。ul/ol 的子项是 li；dl 内只能直接放 dt（术语）和 dd（说明）。课程示例中 p、标题、ul、div 通常是 block，img、a、strong、em 通常是 inline。

03 链接、导航与相对路径

<a href="about.html">About this project</a>
<a href="#forms">Go to the form example</a>
<a href="https://example.com" target="_blank">Example site</a>

./             current folder
images/logo.svg enter a folder
../             parent folder
../../          two levels up

a 用于外部、站内和页内导航，href 指定目标。页内跳转：目标元素写唯一 id="dest"，链接写 href="#dest"。target="_blank" 可在新标签页打开；练习中暂时未知目标可写 href="#"，上线前要替换。好的链接文字准确描述目的地，避免“点击这里”和难读的裸 URL，把重要信息放前面。

路径推理

相对路径从当前文件出发。练习里的 ../图片/md.gif 表示先从路径练习文件回到上一级，再进入图片目录；../../ 再向上两级。绝对路径可从电脑根目录或完整 URL 开始，但某台电脑上的本机绝对路径不能作为可分享项目路径。路径、文件名和大小写必须完全匹配。

04 图片、alt 与媒体

<img src="images/team-photo.jpg" alt="Three students reviewing a design on a laptop" title="Design review">
<audio src="music.mp3" controls loop></audio>
<video src="movie.mp4" controls muted autoplay loop></video>

img src 给出图片位置和名称，title 可显示悬停提示。JPEG/JPG 常用于照片，PNG 常用于支持透明的 Logo/图表，GIF 用于简单动画，SVG 是可缩放矢量图。每个 img 都应有 alt：加载失败时显示替代文字，屏幕阅读器可朗读图片信息，搜索引擎也能理解内容。装饰图写 alt=""，不要省略 alt 或写“image of …”；图片是链接时，alt 写链接目的。

audio 与 video 使用相同的路径思维；controls 显示播放面板，loop 循环，autoplay 尝试自动播放，muted 仅用于视频静音。浏览器通常限制自动播放；静音视频更可能获准 autoplay。布尔属性可以简写为属性名，例如 controls。课程/练习列出视频 MP4、WebM、Ogg，音频 MP3、WAV、OGG；video 需要真实视频文件，不能直接播放视频网站页面 URL。

05 表格与合并单元格

<table>
  <thead><tr><th>Name</th><th>Score</th></tr></thead>
  <tbody><tr><td>Ava</td><td rowspan="2">80</td></tr></tbody>
  <tfoot><tr><td colspan="2">Summary</td></tr></tfoot>
</table>

表格展示二维数据：table 是整体，tr 是行，th 是表头，td 是数据单元格；thead/tbody/tfoot 划分头部、主体和汇总区。合并前先明确目标：跨行保留最上方格子并写 rowspan，跨列保留最左格子并写 colspan，再删除其余被合并的格子。不要用表格做页面布局。

06 表单（Forms）

<form action="/submit">
  <label for="email">Email</label>
  <input id="email" name="email" type="email" placeholder="you@example.com" required>
  <label><input type="radio" name="plan" value="student" checked> Student</label>
  <select name="city"><option selected>Boston</option></select>
  <textarea name="comment"></textarea>
  <button type="submit">Send</button>
</form>

表单收集登录、注册、搜索等信息。action 是提交数据的目标地址；name 是提交字段名，value 是字段值；placeholder 给输入提示，required 表示必须填写。placeholder 不取代真正的 label。

控件来源中的细节
inputtext 单行文本；password 隐藏显示；radio 单选；checkbox 多选；file 上传，multiple 选多个文件。
name / checked同组 radio 使用相同 name 才互斥；checked 指定默认选中。
select/option下拉菜单整体与每个选项；selected 指定默认项。
textarea多行输入；视觉尺寸通常交给 CSS。
buttonsubmit 提交（表单内默认），reset 恢复默认值，button 常配合 JavaScript。
标签与点击范围

完整写法中 label for 必须等于控件的 id；也可把控件包在 label 内。两者都让说明文字可点击。漏掉相同的 radio name、让 label/id 不匹配，或把 reset 放在 form 外都会改变预期行为。

07 语义化 HTML、div 与页面结构

<header>Site identity</header>
<nav><a href="index.html">Home</a></nav>
<main>Important page content</main>
<footer>Copyright and secondary links</footer>

课程笔记把 body 的页面分为四个重点区域：header 帮助说明网站主题，nav 放外部/内部/页内导航，main 放最重要内容，footer 通常放版权与较次要链接。使用正确语义标签能帮助可访问性、SEO 和维护性。

div 是无语义 block 容器，span 是无语义 inline 容器；没有更准确语义时才用。用 div 代替 header/nav/main/footer 会削弱页面含义。容器也可把需要共同布局的子元素放在同一个父元素下，供 CSS Flexbox 或 Grid 使用。

08 Meta、SEO、robots 与文件命名

<meta name="description" content="Notes for learning frontend development.">
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url><loc>https://example.com/index.html</loc></url>
</urlset>
User-agent: *
Disallow: /course-work/

SEO 是用真实、合适的策略使网页更容易被发现。准确的 title、meta name="description"、viewport 与语义结构帮助搜索引擎理解页面。发现过程中，爬虫抓取/索引页面；sitemap.xml 用 urlset、url、loc 列出 URL 并引导爬虫，robots.txt 用 User-agent 和 Disallow 表达爬虫规则。

课程笔记 + 更准确的理解

课程案例把 robots.txt、index.html 与不明显文件名作为作业发布时的保护层。它们不是访问控制：robots 只影响爬虫，index 通常是目录默认入口，知道 URL 的人仍可能访问。文件名应小写、无空格、ASCII、连字符（spinal/kebab case），例如 this-is-a-file-name.html；命名规范帮助路径和协作，不应作为安全措施。

黑帽 SEO 用无关关键词、低质量链接或误导描述操纵排名；白帽 SEO 使用真实内容、正确标签与准确描述。不要为排名让 title/description 与内容不符。

09 版权、Fair Use 与 Creative Commons

课程笔记将 Copyright（版权）说明为对原创表达在一定期限内的法律控制，涉及复制、分发、公开展示、表演与制作衍生作品。Fair Use（合理使用）是依情境判断的有限例外，课程举例批评、评论、新闻报道、研究、教学与学术。

CC含义
BY署名（Attribution）：给原作者署名。
NC非商业（NonCommercial）：不能用于商业目的。
ND禁止演绎（NoDerivatives）：不能修改或创建衍生作品。
SA相同方式共享（ShareAlike）：衍生作品使用相同许可。

使用 CC 媒体时，课程要求记下 Source（来源）、Artist（原作者）、License（许可），并为每个媒体显示或链接 credit statement。可在 Credits 页面给署名文字加 id，从其他页面链接到该位置。&#169; 显示 ©。

10 Emmet、实体与调试

div.box       → <div class="box"></div>
div#box       → <div id="box"></div>
div+p         → sibling elements
div>p         → nested element
span*3        → three spans
div{content}*2 → two divs with content

&nbsp;  &lt;  &gt;  &#169;

Emmet 是编辑器的代码简写；它可快速生成 class、id、同级、父子、重复和文字内容结构，但生成后仍要检查语义、层级与属性。&nbsp; 是不换行空格，&lt; 是 <，&gt; 是 >。

项目踩坑：从浏览器读到的结果倒推

图片、CSS、JS 或链接加载失败时，先从当前 HTML 文件重新算路径，并检查文件名大小写、src/href 拼写和目录层级。接着在 DevTools 的 Elements 看浏览器解析的父子结构，在 Console 查看加载/语法提示。也检查漏写结束标签、重复 id、label/id 不匹配、以及缺少合适的 alt。
