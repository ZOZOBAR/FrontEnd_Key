# FrontEnd_Key

FrontEnd_Key is Siyu's long-term, source-grounded frontend learning knowledge base. It integrates personal notes, CS303 material, and relevant project experience without replacing the original evidence.

The site is static HTML/CSS/JS and works through `file://`; open `index.html` directly.
